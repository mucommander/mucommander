-------------------------
barebones-commander v0.1.0
-------------------------

barebones-commander is a small, security-first dual-pane file manager focused on
SFTP/SSH as the only remote protocol, on Linux and macOS.

It is a fork of muCommander (https://www.mucommander.com,
https://github.com/mucommander/mucommander) with most upstream features removed.

Project page: https://github.com/e6qu/barebones-commander


Requirements
------------

JDK 25 (LTS) or later.

Linux and macOS are the only supported operating systems.
